Universal air-gapped intelligence engine, certified configuration curricula, and Model Context Protocol (MCP) server for AI coding assistants, IDEs, and chatbots.

1-Click AI Tool Setup (Remote MCP & OpenAPI)

Cursor IDE

Add to .cursor/mcp.json or via Features > MCP > Add Server (Type: SSE).

{
  "mcpServers": {
    "mikrotik": {
      "url": "https://mikrotik-skill.vercel.app/sse"
    }
  }
}

Windsurf IDE

Add to ~/.codeium/windsurf/mcp_config.json under mcpServers.

{
  "mcpServers": {
    "mikrotik": {
      "url": "https://mikrotik-skill.vercel.app/sse"
    }
  }
}

Claude Desktop

Add to claude_desktop_config.json using the standard mcp-remote bridge.

{
  "mcpServers": {
    "mikrotik": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mikrotik-skill.vercel.app/sse"
      ]
    }
  }
}

VS Code (Cline / Roo)

Add to Cline MCP settings tab with SSE transport.

{
  "mcpServers": {
    "mikrotik": {
      "type": "sse",
      "url": "https://mikrotik-skill.vercel.app/sse"
    }
  }
}

Claude Code CLI

Execute in your terminal to register the remote MCP server directly.

claude mcp add --transport sse mikrotik https://mikrotik-skill.vercel.app/sse

ChatGPT Custom GPT

In GPT Builder > Actions > Import from URL (Authentication: None).

https://mikrotik-skill.vercel.app/openapi.json

Available Remote Endpoints

SSE /sse
Native Model Context Protocol (MCP) Server-Sent Events endpoint for remote AI agents and IDEs.
GET /openapi.json
OpenAPI 3.1.0 schema specification for ChatGPT Custom GPT Actions, Claude, and REST clients.
GET /health
Liveness probe verifying knowledge gateway availability.
GET /api/v1/knowledge/tracks
Lists all 10 MikroTik Certification Track blueprints (MTCNA, MTCRE, MTCSE, MTCSWE, etc.).
GET /api/v1/knowledge/template?track=mtcre
Returns production-ready, 1-click RouterOS v7 CLI configuration scripts for the requested track.
GET /api/v1/knowledge/prompt
Exports Senior Network Engineer system prompt directives for LLM pair programming.
POST /api/v1/knowledge/sanitize
Redacts passwords, MAC addresses, serial numbers, and VPN tokens from raw RouterOS configurations.
POST /api/v1/knowledge/validate
Verifies FIB table presence and routing mark compliance before firewall mangle rule injection.
